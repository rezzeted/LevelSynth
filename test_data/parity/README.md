# Golden parity (итерация 0)

Каталог для **эталонных входов/выходов** при сравнении поведения C++ с референсным C# (`_edgar_ref`). На итерации 0 достаточно **договорённостей** и пустой структуры; массовая выгрузка из C# или авто-скрипт могут появиться позже.

## Назначение

- Фиксировать сценарии из [docs/parity_dod.md](../../docs/parity_dod.md) (репродьюсibility, overlap, SA-события, энергия, КП) в виде **стабильных артефактов**.
- Дать основу для «smoke golden» и регрессии при изменении генератора.

## Предлагаемый макет (пустые папки при необходимости создаются вручную)

```
test_data/parity/
  README.md           (этот файл)
  scenarios/          (описания сценариев: JSON/YAML или .md + seed)
  expected/           (ожидаемые дампы: .json, .txt — формат по договорённости)
```

## Формат (черновик)

- **Вход**: идентификатор сценария, `seed` (и при необходимости параметры карты), путь к бинарю/режиму сборки — в одном конфигурационном файле или в имени подкаталога.
- **Выход**: сериализованное состояние или детерминированный лог (хэш энергии, число событий SA, список позиций КП и т.д.). Конкретная схема полей **TBD** по мере появления первого golden.
