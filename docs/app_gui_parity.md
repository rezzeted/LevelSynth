# Паритет приложения LevelSynth с Edgar.GUI

Краткое сравнение сценариев **оригинала** (WinForms/WPF Edgar.GUI в Edgar-DotNet) и **порта** (SDL3 + ImGui, `main.exe`).

## Что делает оригинал

- Работа с деревом ресурсов: `MapDescriptions`, `Maps`, `Rooms`, `Images`, `RandomGraphs` и т.д.
- Выбор карты из списка, предпросмотр, генерация, экспорт.
- Полноценный редактор и навигация по файлам в стиле IDE.

## Что делает порт (целевое состояние после плана)

- Загрузка каталога ресурсов с диска: путь задаётся вручную, через `--resources`, через диалог выбора папки (Windows) или перетаскиванием `.yml`.
- Открытие одного файла карты `Maps/*.yml` с автоматическим определением базовой папки (`…/edgar_gui`).
- Генерация и предпросмотр раскладки, экспорт JSON в выбранный файл (диалог сохранения на Windows).
- Понятные сообщения об ошибках загрузки YAML/файловой системы в панели лога.

## Пробелы (намеренно вне скоупа)

- Не клонируется полный UI WPF (списки с миниатюрами, отдельные окна редактора).
- Unity / Unity build не рассматриваются.

## Командная строка

- `main.exe --resources <dir>` — базовая папка с `Maps/` и `Rooms/` (как копия `edgar_gui`).
- `main.exe <path\to\map.yml>` — загрузить одну карту; база выводится из пути (`…/Maps/name.yml` → родитель `Maps`).
- Флаги и путь к `.yml` можно комбинировать; порядок аргументов не важен.

## Ручной чек-лист (регрессия UX)

1. Запуск без `resources/edgar_gui` рядом с exe — fallback на встроенный 4-room cycle, сообщение в логе.
2. Указание валидной папки (копия `resources/edgar_gui`) — список карт не пустой, генерация работает.
3. `--resources <path>` — тот же эффект при старте.
4. Открытие одного `Maps/foo.yml` — в списке только эта карта (или выбрана автоматически).
5. Export JSON — файл появляется по выбранному пути (Windows: диалог «Сохранить»), в логе полный путь; отмена диалога — сообщение «Export cancelled».
6. Ошибка: несуществующий путь — текст ошибки в логе (`Load error: …`), без молчаливого пустого каталога.
7. Перетаскивание `.yml` или папки на окно — загрузка карты или каталога (SDL `SDL_EVENT_DROP_FILE`).
